# Metroid Prime — Xbox 360 Port / Adaptation Project

> **Aviso de estado y legalidad:** Este repositorio documenta la arquitectura, herramientas, flujos de trabajo y notas técnicas para adaptar o portar **Metroid Prime** (GameCube) a la arquitectura **Xbox 360** (PowerPC Xenon / GPU Xenos / formato `.xex`). **No se distribuyen archivos de ROM, ISO originales de GameCube, SDKs oficiales restringidos ni claves cifradas con derechos de autor.** Debes contar con tu propia copia legal del juego.
>
> 
Este proyecto busca investigar, documentar y construir las herramientas necesarias para llevar la experiencia de *Metroid Prime* a consolas Xbox 360 modificadas / homebrew (RGH / JTAG / devkits compatibles con ejecución de `.xex`).

Objetivos principales:
- Analizar los formatos de archivo nativos del disco de GameCube (contenedores, texturas, mallas, audio y scripts).
- Diseñar conversores para adaptar recursos gráficos y de audio a formatos eficientes en Xbox 360.
- Documentar el mapeo de controles (mando GameCube vs. mando Xbox 360) y ajustes de cámara/FOV.
- Mantener un registro claro de avances, pruebas y limitaciones técnicas.
